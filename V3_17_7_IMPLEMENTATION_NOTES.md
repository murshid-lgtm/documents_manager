# V3.17.7 – Quick View Stage UI + Label Sheet Management

- Reworked compact document stages in Case Quick View to prevent overlap.
- Compact stage cards now show stage name, status and date at a glance.
- Edit icon expands only the selected stage to update status/date and access rename/delete.
- Added a Delivery > Label Sheet manager.
- Saved label sheet items can now be reviewed, removed individually, cleared completely, and printed.
- Label Sheet button shows the number of saved labels.
- No database migration is required.
