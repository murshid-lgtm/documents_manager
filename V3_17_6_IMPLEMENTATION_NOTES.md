# V3.17.6 — Courier Split Picker

- Large 94vw / 92vh shipment create/edit modal.
- Shipment details stay compact at the top.
- Left pane: instant search and case accordions for document selection.
- Right pane: persistent shipment basket with selected documents.
- Required Work / Attestation is assigned per selected document in the basket.
- Selected documents remain in the basket while searching for additional cases.
- Search covers tracking, customer, holder, document and stage data already loaded by the app.
- No database migration is required for this UI release.
