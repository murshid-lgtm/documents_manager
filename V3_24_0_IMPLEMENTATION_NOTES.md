# Kenza Tracker Web v3.24.0

## Quick View hierarchy and responsiveness

- Promoted tracking number and customer name into a large full-width identity header.
- Kept mobile, submitted branch, bill number and current physical location visible as compact identity chips.
- Moved all existing operational actions into a compact Quick Actions rail on wide desktop screens.
- Converted Quick Actions into a horizontal compact grid on tablets.
- Converted Quick Actions into a two-column touch-friendly grid on mobile devices.
- Preserved Delivery, Handover, Payment, Appointment, Print Label, Edit Case and Delete Case behavior.
- Preserved the scrollable Activity History panel and 150-event history retrieval.
- Kept all new layout rules scoped to the Quick View modal.

## Safety

- No database migration is required.
- No operational workflow or action handler was changed.
- Operations, Custody, Delivery, Payments and Appointments modules were not modified.
