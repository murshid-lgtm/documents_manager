# Kenza Tracker Web v3.25.0

## Quick View readability update

- Placed the tracking reference and customer name on separate header lines.
- Increased the tracking reference and customer name sizes for stronger hierarchy.
- Realigned the status selector and close control as a consistent right-side header group.
- Increased the size and spacing of mobile, branch, bill and current-location information.
- Increased typography across Quick Actions, KPI cards, document workflows, Case Details and Activity History.
- Tuned the same hierarchy independently for desktop, tablet and mobile breakpoints.

## Safety

- All existing action handlers and workflows are unchanged.
- Activity History still loads up to 150 events with independent scrolling.
- No database migration is required.
- Changes remain scoped to the Quick View modal.
