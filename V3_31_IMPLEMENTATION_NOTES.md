# Kenza Tracker V3.31.0

- Case sharing now creates a premium 1080 × 1350 customer tracking receipt image.
- The receipt includes tracking number, customer, status, branch, mobile, submission date, bill, document summary, QR code and direct tracking link.
- Case card and Quick View Share/WhatsApp actions use the detailed receipt rather than basic text.
- New cases immediately show the generated receipt and the full editable WhatsApp message.
- Customer Tracking Settings in the sidebar allow each signed-in user to set the public tracking-page URL.
- The default tracking page is `https://mellodeals.com/track/`; the app automatically adds `?ref=TRACKING_NUMBER`.
- On supported phones, the system share sheet sends the receipt image and message together. On browsers that cannot attach files directly to WhatsApp, the receipt downloads and WhatsApp opens with the prepared message for manual attachment.
