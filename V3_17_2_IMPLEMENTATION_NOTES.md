# Kenza Tracker V3.17.2

Courier UI refinement:
- Create Shipment modal returned to the same compact width/padding/style as standard app modals.
- Shipment fields use the standard two-column form layout.
- Document selection is grouped by case in accordions.
- Each case can be expanded and documents selected individually or with Select All.
- Each document shows its required attestation/service derived from its active document stages.
- Courier manifest now includes a Required Attestation / Service column.
- Manifest prints in A4 landscape to fit the additional service information.
