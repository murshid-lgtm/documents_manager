# V3.17.11 — Invoice-style New Case

- Rebuilt New Case as a wide invoice-style transaction workspace.
- Persistent searchable document catalog in `public.document_catalog`.
- Existing document names are seeded into the catalog.
- Newly used document names are automatically saved to the catalog after a successful case creation.
- Customer name is the default document holder for every document.
- A small person/add icon allows an alternate holder name only when needed.
- Document line items support quantity, document-level DD, workflow presets, full stage selection, duplication and removal.
- Finance and optional case details remain visible in a sticky right-side summary.
