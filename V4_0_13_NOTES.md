# V4.0.13 — Workflow UI & Searchable Case Baskets

## Quick View

- Close control moved tightly into the top-right corner with a light-red treatment.
- Add Document moved into the Quick Actions rail with an icon.
- Call, WhatsApp, Share and Favorite moved from Case Details to a compact icon dock below the left-side actions.
- Responsive arrangements retained for desktop, tablet and mobile.

## Operations

- Staff & Roles modal rebuilt with an active-staff summary, responsive staff cards, role, assignment count and active indicator.

## Custody

- Increased typography in handover and bulk custody forms.
- Increased Custody card identity, location, metadata, document and action text by approximately 1 px.
- Corrected Quick View button icon/text alignment.
- Existing branch-aware handover, receiving confirmation and document-location behavior are unchanged.

## Appointments

- Replaced manual multiline tracking input in Bulk Add Appointments.
- Added partial case search by tracking, customer, mobile and bill.
- Added ranked results, Add buttons, duplicate prevention, selected-case basket and Remove controls.

## Batch Reports

- Replaced manual tracking-reference textarea with the same searchable Add-to-Batch basket.
- New and edited batches preserve selected cases and require at least one valid case.
- Existing stage updates, case-status updates, pricing and printable report workflow are unchanged.

No database migration is required for V4.0.13. Keep the V4.0.12 Supabase migration applied.
